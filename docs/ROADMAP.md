# SmartCart Build Roadmap

## Phase 1 — Foundation (completed in starter)
- MERN monorepo structure
- MongoDB/Mongoose models for users, products, orders
- JWT authentication API
- Product CRUD API with admin protection
- Order creation and inventory decrement
- Invoice PDF service
- Email service with SMTP configuration
- Initial React/Vite shell

## Phase 2 — Customer experience
- Full product catalog
- Search/filter/sort
- Product details
- Cart context + persistence
- Checkout/address forms
- Order confirmation
- Order history/tracking

## Phase 3 — Admin experience
- Dashboard KPIs
- Product CRUD UI
- Inventory controls
- Order management
- Customer list
- Sales charts

## Phase 4 — Production polish
- Form validation
- Better error handling
- Security hardening
- Image uploads
- Real payment gateway (optional)
- Tests
- Deployment
